# Development Instructions

## Documentation Requirements

- Evaluate every code change, feature, bug fix, and UI change for documentation impact.
- Update `CHANGELOG.md` for every user-facing change, using **Added**, **Changed**, **Fixed**, or **Removed** as appropriate.
- Update `README.md` whenever gameplay, features, installation, configuration, or user instructions change.
- Do not make unnecessary README edits when it remains accurate.
- Include documentation in the same commit or pull request as the related change.
- Before declaring a task complete, report which documentation files were updated. If no documentation update was needed, explain why.
